# Fotografias de produtos lucrescente

Origem: arquivo público de @lu.crescente, extraído em 2026-09-12.

- `_all-downloaded/`: cópia integral das 360 imagens públicas encontradas nos 84 posts.
- Pastas das categorias: cópias agrupadas pelos produtos mencionados na legenda do post.
- `_por_rever/`: imagens cujas legendas não identificam uma das 10 categorias pedidas.
- `catalogo-imagens.csv`: ficheiro, categoria(s), post original, data, dimensões e legenda.
- Uma fotografia de um kit/conjunto aparece em mais de uma pasta quando inclui várias categorias.
- Os ficheiros de origem foram preservados; nada foi apagado.
